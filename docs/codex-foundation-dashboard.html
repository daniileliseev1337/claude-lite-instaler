Номера — реальная последовательность при первой установке. Не начинайте со второго шага: plan не пишет на диск.

00

Перед началом

Проверьте три условия

  • Windows 10 или 11; вход выполнен под обычной учётной записью.
  • Codex client уже установлен. Foundation не устанавливает и не обновляет сам Codex.
  • Архив распакован в отдельную локальную папку; SHA ZIP совпал с файлом .zip.sha256.
Не запускайте PowerShell от администратора. Пакет работает только с текущим пользователем и не меняет credentials, config.toml, hooks, MCP или plugins.
01

Сначала посмотреть

Plan — ноль записей

Откройте PowerShell в распакованной папке. Команда показывает точные назначения, active/quarantine и все конфликты.

.\install.ps1 plan

Запуск .\install.ps1 без аргумента делает то же самое. Если видите BLOCKER, установка ещё не начиналась.

02

После чистого plan

Install — с подтверждением

Installer ещё раз пересчитывает plan. Затем просит ввести INSTALL и показанный Release ID. Любая другая строка отменяет операцию до открытия транзакции.

.\install.ps1 install
Active discovery Core rules, проверенные agents и skills с foundation verdict PASS.
Quarantine Hooks, MCP, plugins и всё недоказанное. Они не импортируются и не исполняются.
03

Проверка результата

Doctor — контроль хэшей

Doctor сверяет active-файлы, transaction state, совместимость и ожидаемый quarantine. Он не исправляет drift автоматически.

.\install.ps1 doctor

Безопасный отчёт для поддержки

.\install.ps1 doctor -ExportReport .\doctor-safe.json

Отправляйте только doctor-safe.json. Не отправляйте config, credentials, cache и содержимое переменных окружения.

04

Что именно доставлено

Inventory — объяснение каждой позиции

Команда перечисляет component ID, тип, verdict, activation reason и health. Quarantine читается как данные — его код не запускается.

.\install.ps1 inventory
05

Если установка прервалась

Rollback — байтовый возврат

Откат восстанавливает только managed paths из snapshot. Изменённый после установки файл не перезаписывается: операция вернёт ROLLBACK_CONFLICT.

.\install.ps1 rollback
!
